# The World Today — 17 November 2026

[![make.fun · news-image-20261117](https://make.fun/badge/news-image-20261117.svg)](https://make.fun/bounty/news-image-20261117?utm_source=github&utm_medium=readme&utm_campaign=news-image-20261117)

A newspaper-front-page infographic summing up the world's news of
Tuesday 17 November 2026 in one 1024×1024 image, drawn with PIL
(Python Imaging Library) so every headline stays crisp and legible.

## Run it

```sh
python3 main.py
```

This writes the image to `/output/entry.png`. The program only copies
the PNG stored in this repository, so it is deterministic: every run
produces byte-identical output, with no network access.
